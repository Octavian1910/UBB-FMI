\## 📌 About This Repository



Welcome to my \*\*Computer Science portfolio at Babeș-Bolyai University (UBB), Faculty of Mathematics and Computer Science (FMI)\*\*.



This repository is a structured collection of my academic work, programming assignments, laboratory exercises, projects, and learning resources developed throughout my university studies.



Its purpose is to document my progress as a Computer Science student, consolidate the concepts I learn, and build a long-term reference for solving increasingly complex software engineering problems.



Rather than being just a collection of source files, this repository represents an evolving record of my development as a programmer — from understanding fundamental programming concepts to working with algorithms, databases, object-oriented design, networking, and more advanced computational problems.



\### 🎯 Repository Goals



\- \*\*Document my academic journey\*\* across university years and semesters.

\- \*\*Consolidate theoretical knowledge\*\* through practical implementations and experiments.

\- \*\*Develop problem-solving skills\*\* by working with algorithms, data structures, and computational techniques.

\- \*\*Improve software engineering practices\*\*, including code organization, testing, debugging, and maintainability.

\- \*\*Build a technical reference\*\* that I can revisit when preparing for examinations, technical interviews, and future projects.

\- \*\*Track continuous improvement\*\* as I learn new programming languages, tools, and development methodologies.

\## 🧠 Topics \& Areas of Study



The repository brings together practical work from multiple areas of Computer Science.

Developing a solid understanding of programming through hands-on exercises and progressively more complex problems.

Learning to design programs using well-defined classes, objects, interfaces, and relationships between components.

\## 📈 Learning Philosophy



My approach to Computer Science is based on understanding concepts rather than simply producing working code.



For every problem, I aim to understand:



\- \*\*The problem:\*\* What exactly needs to be solved?

\- \*\*The reasoning:\*\* Why does the chosen approach work?

\- \*\*The implementation:\*\* How can the solution be expressed clearly in code?

\- \*\*The complexity:\*\* How much time and memory does the solution require?

\- \*\*The design:\*\* How can the implementation be structured for maintainability and reuse?

\- \*\*The verification:\*\* How can correctness be tested, including edge cases?

\- \*\*The improvement:\*\* What alternatives exist, and what are their trade-offs?



I believe that strong programming skills come from combining theoretical understanding, consistent practice, careful debugging, and the ability to explain technical decisions.
